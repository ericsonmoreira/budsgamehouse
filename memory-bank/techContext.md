# Tech Context

The Buds Game House project utilizes a range of technologies to deliver a robust and scalable application.

## Technologies Used

1. Frontend: React, TypeScript, Vite
2. Backend: Firebase (Authentication, Firestore)
3. Styling: CSS Modules, Material-UI components
4. State Management: React Query, React Context

## Development Setup

1. Node.js and Yarn for package management
2. Vite for development server and build process
3. TypeScript for type checking
4. Biome for code linting and formatting

## Technical Constraints

1. Firebase quota limitations
2. Browser compatibility for older versions
3. Performance optimization for large datasets
